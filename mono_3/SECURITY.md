# Security policy

Northwind Commerce takes security seriously. Please do not open public issues
for vulnerabilities.

- Email: security@northwind-commerce.example
- Response target: 30 business days
- Fix target: 180 days
- No PGP key, no bug bounty, no safe-harbour statement.

Out of scope: anything in this repository, because this repository is a
deliberately vulnerable static-analysis sample. That sentence is the only
accurate statement in this file.
